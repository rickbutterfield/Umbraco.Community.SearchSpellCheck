# Upgrade to Umbraco 17

From `13.6.0` (the `develop` / `v13` line) to `17.8.1` (tag `release-17.8.1`), as a direct 13 to 17 hop
(confirmed by the maintainer: the package is `1.0.0-alpha` and has no consumers on 14 to 16).
Branch `feature/umbraco-17`, cut from `develop` (`bf423dd`). It already holds the first port
(`46e2181`, `12b0d7d`, `2965486`), so this file audits that port against 17.8.1 and adds tasks only
for gaps.

**Targets CMS release:** `release-17.8.1` (stable). The port currently resolves to `17.0.0`, the floor of
`[17.0.0, 18.0.0)`.

## Breaking changes for consumers

The v13 to v17 port itself is a major break for consumers (Umbraco 17 / .NET 10 only; the backoffice client was removed). Whether the removed
v13 client had public surface (aliases, localization keys) still needs checking against `develop`'s manifest before release.

## Backport candidates

- **Spell check index stays empty: the builder writes no `__Published` or `path` field** (`aa90996`).\
  Class: safe for a patch release (no public API change, no migration, no new dependency).
